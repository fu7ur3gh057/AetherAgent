Aether – Privacy Policy

Last updated: 19 November 2026

Aether is a personal assistant used by a single person: its developer and owner. This policy describes how the app handles Google user data.

Data accessed

With the owner's consent, Aether requests the Gmail scope https://www.googleapis.com/auth/gmail.readonly (read-only access to email messages and metadata). The app cannot send, modify or delete email.

How data is used

Email content is read only when the owner asks a question in Telegram that requires it (for example searching for or summarising a message). It is used solely to produce the answer for the owner. It is not used for advertising, profiling or sale, and it is not shared with anyone else.

Third-party processing

To produce an answer, the relevant email text is sent to a large language model provider (Google Gemini or Anthropic Claude) under that provider's API terms. No other third party receives it.

Storage and retention

The OAuth token is stored in a file with restricted permissions on the owner's private server. Email content is not stored in a separate database; only the chat conversation with the assistant (which may quote parts of emails) is kept in the owner's private database and can be deleted by the owner at any time.

Revoking access

Access can be revoked at any time at myaccount.google.com/permissions.

Google API Services User Data Policy

Aether's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
